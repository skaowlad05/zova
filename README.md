# ZOVA MVP
ZOVA — Connect. Create. Share.

এই প্রথম ভার্সনটি একটি frontend prototype।
পরবর্তী ধাপে Login, Database, Video Upload, Follow, Like/Comment, Shorts, Live, Wallet এবং Creator Monetization যুক্ত করতে হবে।

## GitHub Pages
1. `index.html` রিপোজিটরিতে আপলোড করুন।
2. Settings → Pages → Deploy from branch → `main` নির্বাচন করুন।
3. Save করুন।
